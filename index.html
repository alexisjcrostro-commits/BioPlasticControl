BioPlasticControl

Para un futuro sostenible

Un sistema automatizado que controla la temperatura y la agitación para fabricar bioplástico a base de almidón de maíz.

Docente: Adrián Guadalupe De La Torre MartinezJesús Gilberto Leal UrdialesEnrique Alexander Eligio SoriaFili De Anda AguilarNatalia Canales del ToroRené Alexander Hurtado MontoyaAlexis Javier Castro RostroOziel Fernando González Hernández

Resumen

Contexto

El proyecto brinda automatización para elaborar bioplásticos que puedan sustituir algunos artículos de plástico. La Zona Metropolitana de Monterrey genera más de 5,000 toneladas diarias de residuos sólidos urbanos y solo una pequeña parte se recupera o recicla. Además, la automatización ayuda a que en el proceso de creación no se desperdicie mezcla.

Objetivo

Desarrollar un sistema automatizado para elaborar bioplástico a base de almidón de maíz, mediante el control de temperatura y agitación.

Resultado clave

Se diseñó y construyó un prototipo con mecanismos automatizados para controlar la temperatura y agitar la mezcla durante la fabricación.

Introducción y justificación

Problema

La acumulación de residuos sólidos y el uso excesivo de plásticos convencionales son un problema ambiental que afecta a las ciudades y sus ecosistemas, porque muchos no se reciclan al 100%.

Justificación

El proyecto propone una alternativa: bioplástico con ingredientes de origen natural y un proceso de fabricación automatizado que evita un desperdicio considerable.

Estado del arte

Mateus Abe y Shishanthi Jayarathna estudiaron la fabricación de bioplásticos a base de almidón e identificaron dificultades en sus propiedades y procesos. Con esos antecedentes, BioPlastic Control busca mejorar el control de fabricación mediante la automatización de temperatura y agitación.

Metodología

Procedimiento

Preparación del prototipo

Se colocó el prototipo automatizado sobre una superficie estable y se verificaron sus conexiones eléctricas. Se agregaron al recipiente los ingredientes del bioplástico: maicena, agua, vinagre y glicerina.

Encendido y monitoreo

Se encendió el sistema y se inició el funcionamiento del Arduino UNO. Se observó el comportamiento de la temperatura mediante el termopar tipo K, con las lecturas en la pantalla OLED.

Calentamiento y agitación

Durante el calentamiento se activó el motor de 5 V para mantener la agitación constante. Al alcanzar los 75 °C, el servomotor reguló la plancha de calentamiento para disminuir la temperatura y evitar el sobrecalentamiento.

Observación y cierre

Se monitoreó la temperatura y los cambios de color y consistencia de la mezcla durante aproximadamente 8 minutos. Al final se apagó el sistema, se detuvo la agitación y se retiró la mezcla para su enfriamiento y evaluación.

Discusión

Los procesos manuales registrados por otros usuarios tienen un desperdicio de entre 45% y 47%. BioPlastic Control obtuvo 17.25%, una reducción estimada de entre 27.75 y 29.75 puntos porcentuales. La pérdida que queda se debe sobre todo a la evaporación durante el proceso, algo esperado.

Conclusión

BioPlastic Control demostró que es posible automatizar la fabricación de bioplástico a base de almidón de maíz con control de temperatura y agitación constante. El prototipo obtuvo un desperdicio de 17.25% y mejoró el aprovechamiento de la materia prima.

El proyecto también abre la posibilidad de crear procesos más eficientes para fabricar productos que sustituyan artículos de uso cotidiano hechos con plásticos convencionales. Así, busca demostrar que la tecnología y la ciencia pueden trabajar juntas para crear alternativas más sostenibles y cuidar el medio ambiente.
